Bijoy to Unicode converter

Turn Bijoy (SutonnyMJ) Word files into Unicode Bangla, with the layout kept. The conversion runs in your browser: your files are never uploaded.

    Only .docx files. For an old .doc or .dot file, open it in Word, choose File → Save As → Word Document (.docx), then drop that file here. The result uses the Nirmala UI font. Words listed under “check by hand” may have converted wrongly, so read them against the original, especially in legal text.
