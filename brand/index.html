Use it

Static sites and plain CSS

<link rel="stylesheet" href="https://www.blankframe.tech/brand/tokens.css">

body { background: var(--bf-bg); color: var(--bf-ink); font-family: var(--bf-font-body); }

Dark mode follows the system. Set data-theme="light" or "dark" on <html> to force one.

Next.js with Tailwind v4

Copy tokens.css and tailwind.css into the app, then in globals.css:

@import "tailwindcss";
@import "./tokens.css";
@import "./tailwind.css";

/* bg-bf-bg  text-bf-ink  border-bf-line  rounded-bf-md  font-bf-display  shadow-bf-card */

Flutter

Copy blankframe_tokens.dart into lib/core/theme/. Bundle the fonts or load them with google_fonts.

MaterialApp(
  theme: bfTheme(Brightness.light, accent: myProductColour),
  darkTheme: bfTheme(Brightness.dark, accent: myProductColourDark),
);
// or the constants: BfColors.of(brightness).line, BfRadius.md, BfSpace.s4, BfMotion.fast

Changing a token

Edit brand/tokens.json, run python3 brand/build_tokens.py, and commit what it writes. --check fails if a file is stale, a text pair drops under 4.5:1, or the home page palette no longer matches.

Shared components

There is no BlankFrame component library, on purpose. Products span Flutter, Next.js, Vite, Swift and static HTML, so a shared component only pays off inside one stack.

Rule: pull a component out only when two products on the same stack already carry the same one. Until then each product uses its own components on top of these tokens.

Status, October 2026: nothing qualifies yet. The only overlap is the English/Bangla switch (lib/i18n.tsx) in Suggest.Bike and TakaTalks, and the two work differently: one keeps the language in the URL, the other in local storage.
